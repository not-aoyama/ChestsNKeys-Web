# Section 508

Welcome to the Section 508 folder of the Chests 'n' Keys source code! Here, the goal is to make Chests 'n' Keys accessible to players with disabilities.

Section 508 Amendment to the Rehabilitation Act of 1973 requires by law that all United States government websites follow certain rules that ensure they're accessible to everybody. Since Chests 'n' Keys has nothing to do with the U.S. government, there is no requirement for it to be Section 508-compliant. However, I would like it to be compliant anyways, because that means that even more people will be able to play the game.

Located within this folder is:

* The Markdown file you're reading right now
* A printer-friendly HTML file that lists all the Section 508 tests I put Chests 'n' Keys through and whether Chests 'n' Keys passed or failed each of them
* A JSON file containing all of the raw testing data. It was exported into HTML form for easy viewing. Holding onto the original JSON file means that I can easily modify and update it when more testing is done.
* `TODO.txt`, which consists of the stuff I need to do to make Chests 'n' Keys pass the tests it's currently failing
* `questions.txt`, which consists of questions I have about the Section 508 process that I need to ask a more experienced tester.
* A simple HTML demo of a text box with placeholder text. I'm going to use this to demonstrate one of the questions in `questions.txt`. This file will be deleted when I'm done with it.
